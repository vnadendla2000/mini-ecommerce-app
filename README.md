# Mini E-Commerce App

A full-stack e-commerce web application built with Node.js, SQLite, and deployed on AWS EC2.

## Live URLs
- Shop: http://18.232.129.235:3000/shop.html
- Login/Register: http://18.232.129.235:3000/auth.html
- Admin Dashboard: http://18.232.129.235:3000/admin.html
- Account Profile: http://18.232.129.235:3000/profile.html
- Product Detail: http://18.232.129.235:3000/product.html?id=1
- Contact Us: http://18.232.129.235:3000/contact.html

## Tech Stack
- Backend: Node.js + Express
- Database: SQLite (local), AWS RDS (configured)
- Cloud: AWS EC2, RDS, IAM
- Frontend: HTML, CSS, JavaScript
- Auth: JWT tokens (custom HMAC-SHA256)
- DevOps: pm2, GitHub
